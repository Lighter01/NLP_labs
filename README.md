# Лабораторные работы по NLP

Репозиторий для лабораторных работ по курсу NLP. Работы оформлены в Jupyter-ноутбуках и используют общий датасет отзывов MyAnimeList и окружение, управляемое через `uv`.

## Структура

- `notebooks/` — ноутбуки с кодом, результатами и выводами; [список готовых работ](notebooks/README.md).
- `lab_tasks/` — условия лабораторных работ.
- `materials/` — лекции и материалы практических занятий.
- `data/raw/` — исходные данные.

Данные, условия и материалы курса не хранятся в Git.

## Настройка и запуск

Установите `uv` и выполните из корня репозитория:

```bash
uv sync --locked --python 3.13
```

Команда создаст `.venv` и установит зависимости из `uv.lock`. Скачайте [датасет MyAnimeList](https://www.kaggle.com/datasets/natlee/myanimelist-comment-dataset-v2) и распакуйте `reviews.csv` и `anime_list.csv` в `data/raw/` (код для этого есть во второй ячейке ноутбука по первой лабораторной).

В VS Code с расширениями Python и Jupyter откройте нужный ноутбук из `notebooks/` и выберите ядро из проектной `.venv`.

Для запуска через JupyterLab в браузере:

```bash
uv run --locked python -m ipykernel install --user --name nlp-labs --display-name "NLP Labs (.venv)"
uv run --locked --with jupyterlab jupyter lab
```

Откройте ноутбук и выберите ядро **NLP Labs (.venv)**.

Для проверки перезапустите ядро и выполните все ячейки сверху вниз. Выполнение должно завершиться без ошибок; проверьте полученные таблицы, графики и выводы, затем сохраните ноутбук. При первом запуске NLTK скачивает необходимые ресурсы. Полный пересчёт первой лабораторной занимает несколько минут.
