# Ноутбуки лабораторных работ

Каждая лабораторная оформляется в отдельном файле `labN.ipynb`: условие, код, результаты и краткие выводы. Готовые ноутбуки содержат сохранённые результаты, доступные для просмотра без повторного расчёта.

## Готовые работы

| Ноутбук | Содержание |
| --- | --- |
| [lab1.ipynb](lab1.ipynb) | Анализ и очистка отзывов, стемминг и лемматизация, расстояние Левенштейна, N-граммные модели, сглаживание, перплексия и генерация текстов. |

Настройка окружения и способы запуска описаны в [README репозитория](../README.md). Для проверки работы выберите проектное ядро, перезапустите его и выполните все ячейки по порядку.
